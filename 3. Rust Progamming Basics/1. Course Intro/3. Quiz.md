2. What is the purpose of using a placeholder construct, such as a `todo!()` macro or raising a `NotImplementedError`, within a function or method that is not yet fully implemented?

3. In Rust, what is the runtime behavior if a function containing the `todo!()` macro is called before its implementation is complete?
    * The program will panic, indicating the functionality is not yet implemented.
